# Cordon de Flèches

Vous touchez quatre flèches ou carreaux non magiques et les plantez dans le sol dans votre espace. Jusqu'à la fin du sort, on ne peut extraire physiquement ces projectiles du sol et, chaque fois qu'une créature autre que vous pénètre dans un espace à 9 m ou moins de l'un de ces objets pour la première fois d'un tour ou qu'elle y termine son tour, l'objet en question jaillit vers elle pour la frapper. La créature doit réussir un jet de sauvegarde de Dextérité, sous peine de subir 2d4 dégâts perforants. Le projectile est alors détruit. Le sort prend fin quand plus aucun de ces projectiles n'est fiché dans le sol. Vous pouvez à l'incantation de ce sort désigner autant de créatures que vous le souhaitez, que le sort ignorera.
Emplacement de niveau supérieur. Le nombre de projectiles qui peuvent être affectés augmente de deux par niveau d'emplacement au-delà du 2°. RL A
